# Aurora patch series

`extern/aurora` is upstream [encounter/aurora](https://github.com/encounter/aurora) at `50e5be3`, plus the port's changes. The changes are stored here as six patches so the submodule can be pinned to upstream and the changes re-applied.

Series base: `50e5be3`. Applying all six to a clean checkout gives the exact tree the port builds against (verified byte-for-byte, see below).

## Apply

    python tools/apply-aurora-patches.py          # apply, or no-op if already applied
    python tools/apply-aurora-patches.py --check  # report only

States the tool reports:

| state | meaning | exit |
|---|---|---|
| applied | every touched file already matches the series result | 0 |
| pristine | every touched file matches upstream `50e5be3`; series is applied | 0 (2 with `--check`) |
| mixed | some files match neither (e.g. partly reverted); nothing is changed | 1 |

The tool needs the `50e5be3` commit in the aurora repo (`git -C extern/aurora cat-file -e 50e5be3^{commit}`). The configure step of `CMakeLists.txt` runs `--check` and warns when the series is not applied.

## Patches

Applied in filename order. Counts are `+`/`-` lines in the patch text.

| file | topic | files | +/- |
|---|---|---|---|
| `0001-gx-color-peek-and-pixel-metric.patch` | `GXPeekARGB`, pixel metric (`GXReadPixMetric`/`GXClearPixMetric`, `GXSetDrawSync`), occlusion queries, tests | 18 | +688 / -84 |
| `0002-gx-fifo-implicit-primitive-close.patch` | `GXBegin` closes a still-open primitive | 2 | +32 / -16 |
| `0003-gx-tev-alpha-r8-compare.patch` | TEV alpha `R8_GT`/`R8_EQ` mapped to RGB8 variants | 1 | +6 / -0 |
| `0004-card-base-path.patch` | `CARDSetBasePath` directory used by `CARDInit` | 1 | +8 / -9 |
| `0005-fsr1-render-scale.patch` | FSR1 upscale (EASU + RCAS) and sharpness API | 4 | +139 / -22 |
| `0006-pass-dump-and-screenshot.patch` | `AURORA_DUMP_PASSES` pass dump and frame screenshot | 12 | +599 / -1 |

Patch 0001 also adds `lib/gfx/pixel_metric.{cpp,hpp}`; patch 0006 adds `lib/gfx/pass_dump.{cpp,hpp}` and `lib/gfx/screenshot.{cpp,hpp}`.

## Verification (run once, when the series was made)

- `git archive 50e5be3` into a scratch dir, then `git apply` of 0001..0006 in order: all six apply cleanly.
- `diff -r -x .git` between that scratch tree and `extern/aurora`: no differences (exit 0).
- Tool test on a scratch clone at `50e5be3`: pristine → apply → rerun reports applied; reverting 0006 is reported as mixed (exit 1).

Not verified here: compiling each intermediate stage. Only the final tree is built and tested.

## Regenerating

Patches are not generated by a repo script. To update after changing `extern/aurora`: commit or leave the working tree as the new target, rebuild the series against `50e5be3`, and re-run the verification above. Keep the topic split. Each patch must apply on top of the previous one.
