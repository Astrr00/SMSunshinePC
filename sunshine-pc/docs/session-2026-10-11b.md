## 13. Why the gate warp restarted the game (observed) and the Bianco select menu

- Cause 1 (fixed): `TSelectDir::direct` (`sms/src/GC2D/SelectDir.cpp:223`) passed an uninitialised 64-bit `void* res` to `OSJoinThread`; the host SDK (`sunshine-pc/src/sdk/os_thread.cpp`) stores only 32 bits, so the probe printed `00007FF700000000`, `res != 0` skipped the select menu (`APP_STATE_GAMEPLAY` with scenario 255), `TMarDirector::setup` failed, `APP_STATE_DONE` set `mNextArea(15,0,0)` + movie 9 and the game restarted at the intro/title (stage 15). Now `void* res = nullptr`. The other `OSJoinThread` callers (`Application.cpp`, `MenuDir.cpp`, ...) do not read the result.
- Cause 2 (fixed): `TSelectMenu::initData` (`SelectMenu.cpp:426`) looked the stage name up with `tags[mStage] & 0xFFFF` (pane tag `'bi_'` = 0x695F, index out of range, `SMSGetMessageData` returned null, `strncpy` crash).
